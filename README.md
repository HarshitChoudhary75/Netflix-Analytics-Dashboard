# 🎬 Netflix Analytics Dashboard | Power BI Report

# 🗂️ Project Overview
This Power BI report presents a dynamic, interactive dashboard analyzing two decades of Netflix data. It uncovers critical trends in subscriber growth, revenue generation, content distribution, and audience preferences, offering strategic insights into Netflix’s global expansion and evolving content strategy.

# 📌 Key Features
📈 Long-Term Trend Analysis: Tracked Netflix's subscriber growth, revenue performance, and content evolution from early 2000s to 2020s.<br>
🎭 Genre Insights: Visualized genre popularity shifts and top-performing content across years and regions.<br>
🌍 Global Expansion View: Mapped Netflix’s regional performance, language diversification, and international audience engagement.<br>
⭐ Top-Rated Content: Analyzed high-performing shows and movies by genre, rating, and geography.<br>
🧭 Interactive Exploration: Provided user-friendly slicers and filters for dynamic insights based on year, region, language, and genre.<br>
🔁 Real-Time Ready: Designed with a modular structure for future live data integration and scheduled refresh support.<br>
